# بسته کامل رادار ۴٫۹٫۱۲ — ۹ نوامبر ۲۰۲۶

مبنای داشبورد: شاخه radar-v4.9.12، کامیت a0e3a2d در مخزن neisiani531-cyber/iran-internet-radar-v10.
این بسته انتشار روی سرور انجام نمی‌دهد. وضعیت فعلی IP در این نوبت ثبت نشده است.

## محتوا و مرز نسخه‌ها

سورس کامل مخزن و داشبورد تک‌فایلی، فونت‌ها، داده‌های سالانه و آزمون‌ها موجود است. runtime-source نسخه جداگانه API و پایش آنلاین از کامیت cc1bea1 است؛ جایگزین API متفاوت موجود در ریشه مخزن V10 نیست و نباید این دو main.py را روی هم کپی کرد. runtime-source شامل منطق بازیابی با شاهد تازه، trigger تکرارنشدن مشاهده و SQL مربوط است. داده زنده، کلید، پایگاه SQLite و تنظیمات خصوصی سرور در بسته نیست.

## اصلاح و کنترل این نوبت

- وابستگی مفقود ساخت cyber_register.json با یک snapshot محلی در apps/command-v4/data رفع شد.
- عنوان تحلیل RTT به مدل حساسیت حسابی تغییر کرد؛ این خروجی اندازه‌گیری تجربه واقعی کاربران نیست.
- اصلاح فوکوس جدول، تفکیک هدف ۴ از کل ترافیک و قید خوداظهاری/شهریور در شاخه ۴٫۹٫۱۲ موجود بود.
- ساخت HTML موفق؛ ۱۷ آزمون تحلیلی، بازشدن ۹ نما، حفظ فوکوس جدول و عرض موبایل ۳۹۰ بررسی شد.
- دو آزمون نگهداری برای بازکردن چندباره DB، به‌روزرسانی تکراری و ممنوعیت بستن رخداد با داده خالی/منجمد موفق بود.
- pytest کامل، Microsoft Office، گردآوری زنده و تطبیق تازه با سرور در این نوبت اجرا نشده است.

## اعتبار داده

عملکرد تا پایان ۱۴۰۳ تأیید ناظر دارد. ارقام ۱۴۰۴ پایان اسفند و ۱۴۰۵ تا پایان شهریور خودارزیابی وزارت ارتباطات است. رقم کل گزارش‌شده ۱۴۰۴ برابر ۷۹٫۰۱۳۹ و ۱۴۰۵ برابر ۷۳٫۰۸۰۳ درصد است. اختلاف تجمیع اهداف، شاخص‌ها و محورها همچنان یک محدودیت داده است؛ کاهش رقم گزارش‌شده به‌تنهایی اثبات افت عملکرد هم‌سنجه نیست. طرح ۵۰ پرسش تحلیلی در docs موجود است؛ همه ۵۰ تحلیل پیاده‌سازی نشده‌اند.

## استفاده

برای مشاهده آفلاین، Radar-v4.9.12-complete.html را باز کنید. برای ساخت مجدد، در apps/command-v4 فرمان npm ci و سپس python3 build.py اجرا شود.

روی Ubuntu، پس از بازکردن بسته، prepare_preview.py فقط پیش‌نمایش v4912-complete-preview.html را می‌نویسد و دو اسکریپت نمایش سیگنال را از index.html منتقل می‌کند. اگر اسکریپت‌ها موجود نباشند یا پیش‌نمایش از قبل وجود داشته باشد متوقف می‌شود. index.html و سرویس‌ها تغییر نمی‌کنند. بازگشت پیش‌نمایش با حذف همان فایل ممکن است؛ پیش از ارتقای اصلی باید capture تازه سرور و مقایسه انجام شود. اجرای runtime-source و تغییر image در این مرحله توصیه یا خودکار نشده است.
