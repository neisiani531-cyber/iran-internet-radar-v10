# رادار اینترنت ایران V10 · CI Bootstrap

این مخزن برای سنجش اجرای واقعی React/TypeScript روی GitHub Actions ایجاد شده است. فقط نمونه اولیه اینترنت ثابت با دو فصل دارای مقادیر صریح در این مخزن قرار دارد؛ **این نسخه انتقال کامل V10.8 یا موتور FastAPI نیست**.

منبع داده نمونه: گزارش فصلنامه ۵۷ سازمان تنظیم مقررات و ارتباطات رادیویی. برای دوره‌های میانی عدد فرضی تولید نشده است.

## Build
`npm install`
`npm run build`

مسیر خروجی: `dist/`. برای نتیجه اجرا به تب Actions مراجعه کنید.
