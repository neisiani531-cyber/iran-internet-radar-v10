# رادار اینترنت ایران | مخزن مادر محصول (V10)

**وضعیت:** مخزن مادر نرم‌افزار تعیین شده؛ پیاده‌سازی محصول کامل هنوز در حال مهاجرت است.

این مخزن عمومی مرجع رسمی **کد نرم‌افزار، رابط React، API، قراردادهای داده، آزمون‌ها، CI و نسخه‌های انتشار** رادار اینترنت ایران است. مرجع مستقل و خصوصی پژوهش و شواهد در مخزن `neisiani53-create/iran-internet-research` باقی می‌ماند.

## وضعیت فعلی
- **موجود:** نمونه اولیه React/TypeScript/Vite با دو دوره رسمی اینترنت ثابت؛ GitHub Actions برای Build.
- **هنوز منتقل نشده:** FastAPI، داده‌های کامل پنج‌فصلی، مقایسه اپراتورها، شبکه‌های اجتماعی و رضایت، رجیستری علمی، E2E.
- **اطلاعات پژوهشی:** طبق گزارش مرجع مورخ ۲۰۲۶-۱۰-۱۵، صفر پرونده از ۲۰ پرونده پذیرش Q5 داشته‌اند. Build سبز به معنی تأیید علمی نیست.
- **مهم:** سه فصل میانی نباید به شکل فرضی ساخته شوند.

## راه‌اندازی توسعه
```bash
npm install
npm run build
npm run dev
```

خروجی قابل انتشار فرانت‌اند: `dist/`. گزارش CI در [GitHub Actions](../../actions) قابل پیگیری است.

هیچ داده خام خصوصی، شناسه شخصی یا ادعای فاقد پذیرش پژوهشی به‌صورت KPI رسمی وارد محصول عمومی نمی‌شود. هر عدد منتشرشده باید واحد، دوره، جامعه/مخرج، منبع و سطح اعتبار مشخص داشته باشد.
