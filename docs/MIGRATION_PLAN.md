## پیشرفت تازه ۲۰۲۶-۱۰-۱۶
- قرارداد عمومی، Snapshot و کنترل مجموع و provenance ثبت شد.
- FastAPI اکنون Snapshot مشترک را در زمان راه‌اندازی بارگذاری می‌کند.
- Workflow آزمون پایتون اعتبارسنجی Snapshot را قبل از pytest اجرا می‌کند.
- **اجرای موفق CI تازه هنوز مستقل تأیید نشده است.**
- Bootstrap React اکنون Snapshot مشترک `packages/contracts/public-fixed-access.snapshot.json` را وارد می‌کند و کارت‌ها و نمودار را از آن می‌سازد. هر دو Workflow وب و API، اعتبارسنجی این Snapshot را پیش از آزمون/Build اجرا می‌کنند. **نتیجه اجرای CI جدید هنوز بررسی نشده است.**

## ترتیب توسعه
1. Baseline را Tag و Lockfile تثبیت کنیم؛ گزارش سبز Build را به SHA متناظر پیوند دهیم.
2. پروژه را با مهاجرت تدریجی به `apps/web` و `apps/api` سازمان‌دهی کنیم؛ CI طی تغییر باید سبز بماند.
3. قراردادهای `packages/contracts` و snapshot عمومی با provenance راه‌اندازی شوند.
4. داده ثابت پنج‌فصلی و مقایسه اپراتور به بخش‌های مشترک React منتقل شوند.
5. رجیستری پژوهشی P01 و صفحات شواهد با برچسب وضعیت روش‌شناسی منتقل شود.
6. آزمون‌های API، E2E، موبایل، RTL، چاپ، CSV و offline برقرار شوند.
7. سپس صفحه ملی، کیفیت، رضایت، اقتصاد، تاب‌آوری، حکمرانی و AI صرفاً با گیت داده اجرا شوند.

## قانون جلوگیری از تکرار کار
- در هر مرحله: commit واقعی + تست انجام‌شده + لینک run و artifact + تعداد گیت‌های علمی + ریسک/مانع.
- هرگز از Build سبز به معنای «محصول کامل»، «داده تأییدشده» یا «پژوهش Q5» نتیجه‌گیری نشود.
- مخزن خصوصی منبع حقیقت پژوهش باقی بماند. پروژه مادر تنها خروجی مجاز قابل ردیابی را مصرف کند.
