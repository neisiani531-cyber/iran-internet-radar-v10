source catalog → source register → evidence/claim/conflict → Q0–Q5 + definition + unit + period + denominator + method + publisher page → PUBLIC_APPROVED یا RESEARCH_PREVIEW یا HOLD/BLOCKED → API و React و در آینده RAG.
