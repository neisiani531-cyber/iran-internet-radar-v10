# سیاست داده و انتشار

این مخزن **عمومی** است. مخزن پژوهشی مرجع محرمانه/اصلی محسوب می‌شود و به‌صورت خودکار mirror نمی‌شود.

## طبقه‌بندی
- `PUBLIC_APPROVED`: داده منتشرشدنی، مجاز برای snapshot و KPI با منشأ.
- `PUBLIC_RESEARCH_CONTEXT`: توصیف روش/منبع بدون ادعای KPI قطعی؛ وضعیت اعتبار باید مشخص باشد.
- `RESTRICTED`: داده خام یا دارای قید استفاده/حریم خصوصی؛ ورود ممنوع.
- `BLOCKED`: ادعای بی‌منبع یا مورد تعارض حل‌نشده؛ عدد نباید عمومی شود.

## چک‌لیست انتشار
۱. مجوز و سیاست منبع برای بازنشر بررسی شود.
۲. شاخص، واحد، دوره، جغرافیا، جامعه و مخرج مشخص باشند.
۳. سند/صفحه و نسخه/تاریخ گردآوری مشخص باشد.
۴. گیت علمی و سطح عدم قطعیت مستقل ثبت شود.
۵. هیچ شناسه فردی، نشانی IP خام حساس، فایل پژوهشی داخلی یا توکن وارد Git نشود.
۶. تعارض‌ها با رأی انسانی و مدرک حل شوند؛ الگوریتم نباید خودسرانه میانگین بگیرد.
۷. خروجی عمومی دارای manifest با checksum و نسخه باشد.

## وضعیت ممیزی ۲۰۲۶-۱۰-۱۶
مخزن خصوصی پژوهش در گزارش ۲۰۲۶-۱۰-۱۵ خود ۰ مورد Q5_ACCEPTED از ۲۰ پرونده گزارش می‌کند. انتقال فایل‌ها به مخزن مادر **هیچ تغییری** در این تعداد نمی‌دهد.

نمونه این مخزن از گزارش رسمی رگولاتوری دو دوره صریح دارد؛ سه فصل میانی این Bootstrap هنوز منتقل نشده است.
